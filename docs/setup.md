# Setup wizard

1. Select **Next** in the MSI wizard.
2. Select **Install**.
3. Open **Discord PDB**.
4. Select **Grant access**.
5. Open **Windows settings**.
6. Set Discord banners to **Off** and Notification Center to **On**.
7. Set Discord PDB banners to **On**.
8. Return to Discord PDB and select **Test**.

Setup is complete when the status is **Running**.
